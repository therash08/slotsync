# ⚡ SlotSync

### Course Planner for Leading University

> **Build your semester without the clashes.**

SlotSync helps Leading University students plan **retake and improvement courses** without manually comparing multiple batch and section routines.

Add your current-semester courses, explore available sections, detect class clashes, and find a routine that fits.

---

## ✨ Key Features

- 🔍 **Automatic Clash Detection** — Detect overlapping class times instantly
- 🔄 **Cross-Batch Section Search** — Explore sections from different batches
- 📚 **Retake & Improvement Planner** — Add extra courses to your current routine
- 📅 **Weekly Routine View** — See all selected classes in one timetable
- 🔀 **Alternative Section Finder** — Find another section when a clash occurs
- ⚖️ **Compare Schedules** — Compare different routine options
- 💾 **Save Schedules** — Save preferred plans in your browser
- 🔔 **Conflict Notifications** — Get notified when selected courses overlap

## 🚀 How It Works

```text
Create Profile
      ↓
Select Current Courses
      ↓
Add Retake / Improvement Courses
      ↓
Check Class Conflicts
      ↓
Find Compatible Sections
      ↓
Build & Save Your Routine
```

Two classes clash when they occur on the same day and their time ranges overlap.

---

## 👤 Local Student Profile

Students can create a profile using:

- Student ID
- Name
- Department
- Batch
- Section

SlotSync is currently **frontend-only**, so profiles and saved schedules are stored in the browser using Local Storage. No backend authentication or cross-device sync is currently provided. :contentReference[oaicite:2]{index=2}
